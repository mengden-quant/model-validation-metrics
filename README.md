# Model Validation Metrics

Production-style Python toolkit for model validation metrics used in credit risk and model risk management.

## Initial Scope

- Discrimination: AUC, Gini, KS
- Calibration: Binomial test, Hosmer-Lemeshow test, Hirfindahl-Hirschman index.
- Stability: PSI and drift diagnostics.
- Intervals: bootstrap confidence intervals.

Early development.
